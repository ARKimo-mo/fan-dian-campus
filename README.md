# 饭点儿 · 校园食堂点评推荐

面向大学生的可交互产品原型：搜索菜品与窗口、食堂筛选、预算与辣度偏好、避开食材、评分/价格/等餐排序、本周新菜、避雷参考、菜品详情、收藏、写点评，以及带推荐理由的一键选餐。

虚构示例校园：青禾大学。菜品、价格、排队与评价均为示例。新增点评、推荐偏好、收藏仅保存在当前浏览器。没有后台、跨用户同步或实时校园数据。选餐使用透明的本地规则，先满足预算与忌口，再参考评分、排队与尝鲜偏好，不调用大模型。

## 本地运行

Node.js 20+。运行 `node scripts/serve.cjs`，访问 `http://127.0.0.1:4173`。应用运行不需要安装依赖，所有图标、图片、脚本与样式均为本地资源。浏览器验证需 `npm install` 后运行 `npm test`，默认使用 Windows Edge，也支持 `BROWSER_PATH` 环境变量。

## 固定部署

GitHub Pages 使用同一仓库与同一域名，后续只需推送 main 分支即可更新。请勿更改仓库名、账号名或 Pages 域名。`.github/workflows/deploy.yml` 只发布网页与 assets，不会公开工作区中的其他文件。
